Each account plan type has a separate line using the shared dashboard palette. The default selection favors the most recent sampled model/effort; a manual selection stays in place while data refreshes, and Reset selection restores the default.

Every point divides total reported output tokens by the sum of those requests' full recorded durations within the existing overview bucket size: one hour for 1d, six hours for 7d and one day for 30d. Reported output tokens include reasoning tokens and are used without subtracting or adding reasoning again. Duration includes thinking and time to first output, so short delivery bursts are not treated as the whole generation. Overlapping request durations are counted separately: three parallel chats each generating 25 tokens per second of their own duration still show 25 tok/s. Successful requests with positive duration and output contribute even when first-token timing is absent, including reasoning-only generations. Missing samples are null gaps and lines do not connect across them. A timestamp tooltip includes account-type values and sample counts beside a thin theme-aware guide, without a filled hover band. The 1d view shows hourly averages across the last 24 hours, not one average for the whole day.
